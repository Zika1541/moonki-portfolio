# 다섯 해의 기록

2021–2026. 인공지능 학부 4년과 군 복무 2년 동안 만든 기록의 색인.

김문기 · 전주대학교 인공지능학과

**→ https://Zika1541.github.io/moonki-portfolio/**

## 무엇이 있나

- **색인** — 연도 → 영역 → 항목. 정리된 파일 1,172개와 손글씨 학습 노트 105장의 분포
- **연표** — 방향이 바뀐 지점 12개
- **작업** — 프로젝트 11건. 각 항목의 마지막 줄은 반드시 **한계**다

## 방법

모든 수치에 `[실측] · [산출] · [추정]` 중 하나를 붙이고, 근거가 없으면 항목을 삭제한다.
결론이 예뻐지는 순간에 자기 결론을 반증한다.

2026년 전주 상권 분석에서 이 규칙으로 통념 3개를 기각하고, 자기 분석 1개를 철회하고,
확신도 1개를 하향하고, 가정 1개를 폐기했다. 그중 두 번은 결론이 오히려 강해졌고 한 번은 새 발견이 나왔다.

같은 규칙을 내 글에도 적용했다. 군 복무 중 1년간 쓴 현장 관찰 35편을 5년 6개월치 실측 데이터에 대조해
**2편을 철회하고 1편의 적용 범위를 줄였다.**

## 개인정보 · 자료 취급

학번·연락처·주소·주민등록번호는 이 저장소 어디에도 포함되지 않는다.
